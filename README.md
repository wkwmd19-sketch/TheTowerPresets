# The Tower Idle — 프리셋 보관소 v1.1.15

블랙/화이트 테마의 로컬 개인 프리셋 사이트입니다. 인게임 데이터와 별개로 **사이트 운영 프리셋 6개**, 불협 전투기록, JSON 백업을 관리합니다.

## 실행

1. ZIP을 풀고 **`index.html`**을 Chrome 또는 Edge로 엽니다.
2. 왼쪽 메뉴 `00 전투기록`, `01 파밍`부터 `06 (미식)토너먼트` 중 하나를 선택합니다.
3. 상단 **DAT 불러오기**에서 The Tower 게임의 `.dat` 저장파일을 선택합니다. 화면의 확인창에서 갱신 대상을 검토한 뒤 진행합니다.
4. 사이트 수동 변경은 **세팅 편집**을 이용하고, 중요한 변경 뒤에는 **JSON 백업**으로 별도 파일을 보관하세요.
5. 브라우저에서 Web Crypto/GZIP이 비활성화되어 DAT 분석을 시작하지 못하면 이 폴더에서 `python -m http.server 8000`을 실행한 뒤 `http://localhost:8000`으로 접속해 주세요.

> DAT는 브라우저 내부에서만 복호화/분석됩니다. 서버에 전송하거나 파일 내용을 업로드하지 않습니다. 원본 `.dat` 파일은 배포 ZIP에도 포함하지 않았습니다.

## DAT 갱신 범위 — 명시적으로 허용한 항목만

| 갱신 항목 | DAT 데이터 / 적용 범위 |
| --- | --- |
| **전투기록** | T1~T24, 불협 공격·체력·코인·궁무 최고 웨이브. 일반 웨이브와 배율은 읽지 않음 |
| **작업장** | 게임의 5개 작업장 프리셋: 공격·방어·유틸·작업장 강화의 레벨 |
| **봇** | 게임의 5개 봇 프리셋: 활성 봇, 기본 스탯 4개 레벨, 봇+ 레벨 |
| **카드** | 게임의 5개 카드 프리셋: 장착 카드 순서·구성, 해금 카드 마스터리 표시 |
| **가디언** | 실제 장착된 칩을 확인한 게임 가디언 프리셋 2개: 슬롯 1·2 장착 명칭 |

**갱신하지 않는 항목:** 운영방향, 연구실, 모듈, 적 우선순위, 특전, 사이트 개별 프리셋 선택/연결 상태, 작업장 잠금, 봇+ 잠금·활성 UI 설정, 직접 설정 저장값. 이 항목들은 기존에 수동 편집했던 값을 그대로 유지합니다.

- 게임 프리셋에 **연결된** 항목은 해당 게임 프리셋 데이터가 갱신되면 새 값으로 표시됩니다.
- **직접 설정 (이 프리셋 전용)** 선택값은 DAT 가져오기에서 절대 덮어쓰지 않습니다.
- DAT 분석 중 오류가 발생하거나 확인창을 취소하면 현재 사이트 설정을 변경하지 않습니다.
- DAT 파일 구조가 변경되거나 지원하지 않는 카드 ID 등이 나오면 임의 추정 없이 오류를 알립니다.
- `.dat`는 **읽기 전용**입니다. 게임 저장파일을 변경하거나 다시 쓰지 않습니다.
- 기존 v1.1.11 JSON과 동일한 브라우저 저장 키를 사용하며, v1~v12 JSON 백업 복원을 지원합니다.

## 프리셋 항목 순서

**01 운영방향 → 02 작업장 → 03 연구실 → 04 카드 → 05 봇 → 06 모듈 → 07 가디언 → 08 적 우선순위 → 09 특전**

항목 이동 메뉴는 스크롤 중에도 상단에 고정되고, 오른쪽 **최상단** 버튼을 유지합니다.

## 주요 기능 유지

- 작업장 레벨 증감과 일반 스탯별 잠금, 강화 잠금 제외
- 연구실 레벨 슬라이더, 카드 장착/마스터리, 봇 및 봇+ 편집
- 모듈 주·보조 장착, 가디언 2개 슬롯, 드래그 적 우선순위, MAX 연구 특전명·8개 금지, 자동 선택 13순위 및 미지정 전체 목록
- 편집 취소·완료, 연결 게임 프리셋/직접 설정 선택, 프리셋 비교
- JSON 백업/복원, 전투기록 수동 편집 및 불협 배율 그래프·표

## 기술 / 개인정보

- TDS1: HMAC-SHA256 검증 → AES-256-CBC → 마스킹 해제 → GZIP → NRBF 파싱
- `dat-decoder.js`는 원본 전체 데이터를 외부로 보내지 않고, 필요한 필드만 선택해 UI에 돌려줍니다.
- 게임 파일·사용자 계정 정보가 ZIP에 포함되지 않습니다.
- GitHub `main` 브랜치에 배포하는 정적 웹사이트입니다.
- 제3자 코드 출처는 `THIRD_PARTY_NOTICES.md`에서 확인할 수 있습니다.

## v1.1.14 수정 사항

- 모듈 드롭다운은 공격/방어/발전기/코어 부위의 대응 모듈만 표시하며, 배치는 공격·발전기 / 방어·코어 순서입니다. 주·보조 모듈은 각각 선택합니다.
- 모듈 영역 상단의 중복 장착 조합 안내는 삭제했습니다.
- 적 우선순위는 드래그로 순서를 조절할 수 있고 화살표도 유지합니다. `프로텍터→수호자`, `스포트라이트→스포트라이드 범위 내`로 표시합니다.
- 특전 이름은 일반특전 보너스 연구 MAX(25%), 교환특전 개선 연구 MAX(10%) 기준으로 표시하며, 인게임에서 확인된 보스 체력 77% 등은 스크린샷을 우선 반영했습니다. 이는 **표시 이름** 업데이트이며 인게임 런 결과나 실제 연구 레벨을 수정하지 않습니다. 이전 JSON에 저장된 특전 이름도 같은 항목으로 인식합니다.
- 금지 특전은 일반(파랑)/궁무(초록)/교환(보라) 색상으로 분류하며 8개 선택 시 미선택 후보가 잠깁니다. 이미 선택한 특전은 선택칩 또는 목록에서 다시 눌러 해제합니다.
- 자동선택 특전은 전체 목록을 표시합니다. 1~13위까지만 우선순위가 부여되고 나머지는 미지정으로 표시합니다. 드래그 또는 위·아래 버튼으로 미지정 특전과 지정 특전의 순서를 바꿀 수 있으며, 기존 백업의 선택 순위와 이름을 유지하도록 구명칭 변환을 지원합니다.

GitHub Pages 배포 시에도 모든 프리셋 정보는 현재 브라우저 로컬 저장공간에만 저장됩니다.

## v1.1.14 모듈 부위 분류 수정

- 프젝자(프로젝트 펀딩) / 회복 보너스: 발전기 드롭다운으로 이동 (방어에서 제거).
- 전술 탄막: 코어 드롭다운으로 이동 (공격에서 제거).
- 자석후크: 코어 드롭다운에 추가.
- 기존에 누락된 축소광선: 공격 드롭다운에 추가.
- 과거 버전에서 다른 부위에 장착한 이름은 자동 삭제·이동하지 않고 안내문으로 표시하여 수동으로 올바른 부위에 재장착할 수 있게 합니다.
- 기존 프리셋과 브라우저 저장키, JSON 구조, DAT 갱신 범위는 그대로입니다.


## v1.1.15 특전 우선순위 표시

- 금지 특전으로 지정한 항목은 자동선택 순위에서 제외하며, 목록 맨 아래 별도의 빨간색 ‘금지 특전’ 구역으로 모아 표시합니다.
- 저장된 과거 JSON에서 금지 특전이 상위 13개 안에 있던 경우 해당 순위를 비웁니다. 남은 특전의 순서는 그대로 보존하며 자동으로 다른 특전을 승격시키지 않습니다.
- 금지를 해제하면 미지정 목록으로 돌아옵니다. 빨간색 항목의 ‘× 해제’ 버튼으로도 금지를 해제할 수 있습니다.
- 13위 이내의 자동선택 순위 조정·드래그 기능과 기존 DAT 가져오기 대상은 유지합니다.
